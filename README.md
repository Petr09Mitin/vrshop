# VR Супермаркет

## Формулировка идеи

«VR Супермаркет» - это интерактивное приложение в среде VR, симулирующее супермаркет. Пользователь погружается в реалистично смоделированное пространство магазина, где может свободно передвигаться, а также взаимодействовать с товарами и корзиной. Приложение позволяет получать информацию о товаре при взаимодействии с ним (цена, описание), добавлять понравившиеся предметы в виртуальную корзину и оформлять заказ.

## Определение ключевых механик (MVP)

*   **Свободное перемещение по локации**: система передвижения (smooth locomotion) по виртуальному торговому залу.
*   **Взаимодействие с товарами**: Механика захвата объектов контроллерами, их осмотр, возможность взять товар с полки.
*   **Система информации о товаре**: При осмотре товара пользователю отображается всплывающая панель с ключевой информацией: название, цена, краткое описание.
*   **Корзина и оформление заказа**: Виртуальный интерфейс в фиксированной точке пространства, отображающий состав корзины, итоговую сумму и позволяющий провести процесс оформления заказа.

## Выбор механики с наибольшими рисками

**Взаимодействие с товарами**

Наибольшие технические и UX-сложности заключаются в реализации удобного и стабильного взаимодействия с товарами.

**Риски**:
*   Неточность физики захвата объектов (товар может выпадать из руки, пролетать сквозь полки).
*   Некорректная коллизия объектов (наложение товаров друг на друга).

Эта механика является фундаментальной для всего пользовательского опыта. Если не будет возможности брать предметы без багов, это вызовет раздражение и сведет на нет все преимущества VR-магазина.

**Задача для прототипа**: Создать прототип с примитивными объектами (кубы, цилиндры), имитирующими товары, и отработать на них механику физического взаимодействия: захват, отпускание, столкновение с другими объектами и окружающей средой. Цель - добиться точного, предсказуемого и комфортного для пользователя поведения.
